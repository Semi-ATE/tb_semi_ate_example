# tb_semi_ate_example
This is a testbench example for semi-ate.

It only works in conjunction with https://github.com/Semi-ATE/Semi-ATE. Instructions on how to use the project can be found at https://semi-ate.github.io/Semi-ATE/exampleProject/exampleproject.html

If you don’t need all the definitions for masksets,dies, packages, devices and prodcuts  when starting a new project, you can also use this example as a starting point for your own project.
